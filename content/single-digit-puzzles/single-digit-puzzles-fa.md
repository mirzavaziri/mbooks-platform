### ۱.۱ تخم‌مرغ‌های پیرزن

[تمرین]
برچسب: eggs
نوع: محض، المپیاد ریاضی
متن: پیرزنی سه دختر دارد که در روستا تخم‌مرغ می‌فروشند. یک روز به دختر کوچک ۵، به دختر وسطی ۷ و به دختر بزرگ ۹ تخم‌مرغ می‌دهد و می‌گوید: «همه را در جمعه‌بازار بفروشید. قیمت را دختر بزرگ تعیین می‌کند و در هر لحظه هر سه نفر باید به یک قیمت بفروشید. ولی شب باید پول هر سه نفر برابر باشد.» هیچ تخم‌مرغی مجانی داده نمی‌شود، دخترها به هم تخم‌مرغ نمی‌فروشند و به هم پول نمی‌دهند. چه کنند؟ *(حدود ۱۰ دقیقه)*
راهنمایی ۱: «در هر لحظه» با «در تمام روز» یکی نیست.
راهنمایی ۲: اگر تخم‌مرغ‌ها تکی فروخته شوند، یک مشتری ممکن است صبح زود همه را بخرد. تخم‌مرغ‌ها را بسته‌بندی کنید.
پاسخ تشریحی: دختر بزرگ اول تخم‌مرغ‌ها را فقط در بسته‌های ۳تایی عرضه می‌کند. دختر کوچک ۱ بسته دارد، وسطی ۲ و بزرگ ۳ بسته. هر قدر هم مشتری بیاید، در دستشان ۲، ۱ و ۰ تخم‌مرغ می‌ماند. بعد قیمت عوض می‌شود و باقی‌مانده‌ها تکی فروخته می‌شوند.

اگر قیمت بسته $p$ و قیمت تخم‌مرغ تکی $q$ باشد، پول سه دختر $p+2q$، $2p+q$ و $3p$ است. برابری اولی و دومی یعنی $p=q$. پس بسته‌ی ۳تایی باید هم‌قیمتِ یک تخم‌مرغ تکی باشد، مثلاً هر دو یک سکه. آخر روز هر کدام ۳ سکه دارند.

ایده: با یک قیمتِ ثابت، پول هر کس با تعداد تخم‌مرغ‌هایش متناسب است و برابری غیرممکن است. تغییر قیمت در طول روز این تناسب را می‌شکند. شگفتی این است که اول باید ارزان فروخت.

[حاشیه: آزاد]

### ۱.۳ جزیره‌ای که وجود ندارد

[تمرین]
برچسب: island-atleast
نوع: محض
متن: همان ۹ نفر، ولی این بار نفر $i$ام می‌گوید: «دست‌کم $i$ نفر از ما دروغگوییم.» چه کسی راستگوست؟ *(حدود ۵ دقیقه)*
راهنمایی ۱: اگر $L$ نفر دروغگو باشند، حرف چه کسانی درست است؟
راهنمایی ۲: تعداد دروغگوها را از دو راه بشمارید.
پاسخ تشریحی: اگر $L$ دروغگو داشته باشیم، جمله‌ی نفرهای ۱ تا $L$ درست است و بقیه دروغ می‌گویند. پس دروغگوها نفرهای $L+1$ تا ۹ هستند و تعدادشان $9-L$ است. باید $9-L=L$ باشد، که با عدد صحیح ممکن نیست. چنین جزیره‌ای وجود ندارد.

ایده: فقط یک کلمه («دقیقاً» به جای «دست‌کم») همه‌چیز را عوض کرد. با تعداد زوجی از ساکنان، مثلاً ۸ نفر، جواب وجود دارد: نیمه‌ی اول راستگو و نیمه‌ی دوم دروغگو.

### ۱.۵ مجموع و حاصل‌ضرب

[تمرین]
برچسب: sum-product-dialog
نوع: محض، المپیاد ریاضی
متن: دو رقم از ۱ تا ۹ انتخاب شده‌اند (ممکن است برابر باشند). به الف حاصل‌ضرب آن‌ها و به ب مجموعشان را گفته‌اند و هر دو این را می‌دانند.
الف: «نمی‌دانم دو رقم چیست.»
ب: «من هم نمی‌دانم.»
الف: «حالا می‌دانم.»
دو رقم چیست؟ *(حدود ۱۵ دقیقه)*
راهنمایی ۱: حرف اول الف یعنی حاصل‌ضرب به بیش از یک شکل نوشته می‌شود. فهرست این حاصل‌ضرب‌ها را بنویسید.
راهنمایی ۲: حاصل‌ضرب ۴ را در نظر بگیرید.
پاسخ تشریحی: جواب ۱ و ۴ است. الف حاصل‌ضرب ۴ را دارد که یا ۱×۴ است یا ۲×۲. ب مجموع ۵ را دارد و با اطلاعات خودش هنوز نمی‌داند. اگر جفت ۲ و ۲ بود، ب مجموع ۴ را داشت و چون ۴ فقط از ۱+۳ و ۲+۲ ساخته می‌شود و ۱×۳ یکتاست، بعد از حرف الف می‌فهمید جواب ۲ و ۲ است. ب گفت نمی‌داند، پس الف می‌فهمد جواب ۱ و ۴ است. برنامه‌ی زیر نشان می‌دهد این تنها جواب است.

[کد: قابل‌اجرا]
```python
from collections import Counter
pairs = [(a, b) for a in range(1, 10) for b in range(a, 10)]
prod = lambda p: p[0] * p[1]
summ = lambda p: p[0] + p[1]

def keep(S, key, unique):
    c = Counter(key(p) for p in S)
    return [p for p in S if (c[key(p)] == 1) == unique]

S = keep(pairs, prod, False)   # الف: نمی‌دانم
S = keep(S, summ, False)       # ب: من هم نمی‌دانم
S = keep(S, prod, True)        # الف: حالا می‌دانم
print(S)
```

### ۱.۶ عدد خودشمار

[تمرین]
برچسب: self-describing
نوع: محض، المپیاد ریاضی
متن: عددی ۱۰رقمی بیابید که رقم اولش بگوید چند رقم ۰ در آن هست، رقم دومش بگوید چند رقم ۱ دارد، و همین‌طور تا رقم دهم که می‌گوید چند رقم ۹ دارد. *(حدود ۱۵ دقیقه)*
راهنمایی ۱: مجموع رقم‌های این عدد چند است؟
راهنمایی ۲: عدد صفرهای زیادی دارد. رقم اول را بزرگ بگیرید.
پاسخ تشریحی: جواب ۶۲۱۰۰۰۱۰۰۰ است و یکتاست. مجموع رقم‌ها برابر تعداد کل رقم‌ها، یعنی ۱۰ است. این شرط جست‌وجو را خیلی کوچک می‌کند: شش صفر، دو تا یک، یک دو و یک شش.

[کد: قابل‌اجرا]
```python
def compositions(n, k):
    if k == 1:
        yield (n,)
        return
    for i in range(n + 1):
        for rest in compositions(n - i, k - 1):
            yield (i,) + rest

for c in compositions(10, 10):
    if c[0] > 0 and all(c.count(d) == c[d] for d in range(10)):
        print(''.join(map(str, c)))
```

با ۹ لیوان نمی‌شود. مجموع ۹ عدد فرد، فرد است، ولی هر حرکت ۸ برگرداندن اضافه می‌کند و کل برگرداندن‌ها همیشه زوج می‌ماند.

ایده: به جای وضعیت لیوان‌ها، تعداد برگرداندن‌ها را بشمارید.

### ۳.۵ دنباله‌ی لنگفورد

[تمرین]
برچسب: langford
نوع: محض، المپیاد ریاضی، المپیاد کامپیوتر
متن: رقم‌های ۱، ۱، ۲، ۲، ۳، ۳، ۴، ۴ را طوری در یک ردیف بچینید که بین دو ۱ یک رقم باشد، بین دو ۲ دو رقم، بین دو ۳ سه رقم و بین دو ۴ چهار رقم. با دو تا از هر کدام از ۱ تا ۵ چطور؟ *(حدود ۱۵ دقیقه)*
راهنمایی ۱: دو ۴ را اول بگذارید؛ جای کمی برایشان هست.
راهنمایی ۲: برای قسمت دوم، جایگاه‌ها را ۱ تا ۱۰ شماره‌گذاری کنید و مجموع همه‌ی جایگاه‌ها را از دو راه حساب کنید.
پاسخ تشریحی: ۴، ۱، ۳، ۱، ۲، ۴، ۳، ۲. به جز وارونه‌اش، جواب یکتاست.

با ۱ تا ۵ ممکن نیست. اگر رقم $k$ در جایگاه $a_k$ و $a_k+k+1$ بنشیند، جمع همه‌ی جایگاه‌ها $\sum (2a_k + k + 1)$ است که باید برابر $1+2+\dots+10=55$ باشد. پس $2\sum a_k + 20 = 55$ و سمت چپ زوج است، سمت راست فرد. در حالت کلی دنباله‌ی لنگفورد برای $n$ فقط وقتی هست که $n$ به پیمانه‌ی ۴ برابر ۰ یا ۳ باشد.

[کد: قابل‌اجرا]
```python
def langford(n):
    seq, out = [0] * (2 * n), []
    def place(k):
        if k == 0:
            out.append(seq[:]); return
        for i in range(2 * n - k - 1):
            if seq[i] == 0 and seq[i + k + 1] == 0:
                seq[i] = seq[i + k + 1] = k
                place(k - 1)
                seq[i] = seq[i + k + 1] = 0
    place(n)
    return out

for n in range(3, 8):
    print(n, len(langford(n)) // 2)
```

[حاشیه: نکته‌ی تاریخی]
دادلی لنگفورد، ریاضی‌دان اسکاتلندی، این مسئله را در ۱۹۵۸ مطرح کرد؛ می‌گویند پس از تماشای بازی پسرش با مکعب‌های رنگی.

ایده: با دو بسته‌ی نابرابر $a > b$، نفری که نوبتش است فقط و فقط وقتی برنده است که $\frac{a}{b}$ از نسبت طلایی $\varphi \approx 1.618$ بیشتر باشد. اینجا $\frac94 = 2.25$ است.

[کد: قابل‌اجرا]
```python
from functools import lru_cache
phi = (1 + 5 ** 0.5) / 2

@lru_cache(None)
def wins(a, b):          # آیا نفری که نوبتش است برنده است؟
    a, b = max(a, b), min(a, b)
    return any(not wins(a - m * b, b) for m in range(1, a // b + 1) if a - m * b >= 1)

print(wins(9, 4))
print(all(wins(a, b) == (a / b > phi) for a in range(2, 40) for b in range(1, a)))
```

lines = [(0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6)]

@lru_cache(None)
def value(board, turn):  # ۱ = برد، ۰ = مساوی، ۱- = باخت برای نفری که نوبتش است
    board, used = list(board), set(board) - {0}

    cells = [i for i in range(9) if board[i] == 0]
    if not cells or not mine:
        return 0
    best = -1
    for c in cells:
        for x in mine:
            board[c] = x
            win = any(all(board[i] for i in L) and sum(board[i] for i in L) == 15 for L in lines)
            v = 1 if win else -value(tuple(board), 1 - turn)
            board[c] = 0
            best = max(best, v)
    return best

good = []

        if -value(tuple(b), 1) == 1:
            good.append((c, x))

متن: دو ستون سکه با ۹ و ۶ سکه داریم. هر کس در نوبتش یا هر تعداد سکه از یک ستون برمی‌دارد، یا تعداد برابری از هر دو ستون. هر کس آخرین سکه را بردارد برنده است. نفر اول چه کند؟ *(حدود یک جلسه)*

پاسخ تشریحی: وضعیت‌های بازنده تا ۱۰ این‌ها هستند: (۰،۰)، (۱،۲)، (۳،۵)، (۴،۷)، (۶،۱۰). اختلاف دو ستون در آن‌ها ۰، ۱، ۲، ۳، ۴ است و هر عدد طبیعی دقیقاً یک بار در این جفت‌ها ظاهر می‌شود. نفر اول از هر دو ستون ۲ سکه برمی‌دارد و (۷،۴) می‌سازد. این تنها حرکت برنده است.

ایده: وضعیت $n$امِ بازنده $(\lfloor n\varphi \rfloor, \lfloor n\varphi^2 \rfloor)$ است، با همان نسبت طلایی که در بیسکوئیت‌های مسموم دیدیم.

[کد: قابل‌اجرا]
```python
from functools import lru_cache

@lru_cache(None)
def winning_moves(a, b):
    moves = [(a - k, b) for k in range(1, a + 1)] + \
            [(a, b - k) for k in range(1, b + 1)] + \
            [(a - k, b - k) for k in range(1, min(a, b) + 1)]
    return [m for m in moves if not winning_moves(*m)]

print([(a, b) for a in range(11) for b in range(a, 11) if not winning_moves(a, b)])
print(winning_moves(9, 6))
```

نوع: محض، الگوریتم، علوم کامپیوتر
متن: عددی از ۱ تا ۹ در ذهن من است. شما سؤال‌های بله/نه می‌پرسید. با چند سؤال مطمئناً عدد را پیدا می‌کنید؟ حالا فرض کنید من اجازه دارم حداکثر یک بار دروغ بگویم. چند سؤال لازم است؟ *(حدود یک جلسه)*
راهنمایی ۱: بدون دروغ، هر سؤال حالت‌ها را حداکثر نصف می‌کند. با یک دروغ، هر عدد چند «داستان» ممکن دارد؟
راهنمایی ۲: شمارش حالت‌ها می‌گوید ۶ سؤال کافی است. سؤال اول را بررسی کنید.
پاسخ تشریحی: بدون دروغ ۴ سؤال، چون $2^3 < 9 \le 2^4$.

با یک دروغ و $q$ سؤال، هر عدد $q+1$ داستان ممکن دارد: هیچ دروغی، یا دروغ در یکی از $q$ سؤال. همه‌ی این داستان‌ها باید دنباله‌ی جواب متفاوتی داشته باشند، پس $9(q+1) \le 2^q$ و این یعنی $q \ge 6$. با ۶ سؤال $9 \times 7 = 63 \le 64$ و جا تنگ است ولی به نظر کافی است.

ولی کافی نیست. فرض کنید سؤال اول $a$ عدد را «بله» و $9-a$ عدد را «نه» قرار دهد. اگر جواب «بله» باشد، $a$ عدد بدون دروغ و $9-a$ عدد با یک دروغِ مصرف‌شده می‌مانند و ۵ سؤال باقی است. شمارش داستان‌ها می‌گوید $6a + (9-a) \le 32$، یعنی $a \le 4$. با جواب «نه» به همین ترتیب $a \ge 5$. هیچ $a$ای هر دو را ندارد. پس ۷ سؤال لازم است و برنامه‌ی زیر نشان می‌دهد ۷ کافی است.
جواب عددی: 7
برچسب کادر: تعداد سؤال با یک دروغ

[کد: قابل‌اجرا]
```python
from functools import lru_cache

@lru_cache(None)
def solvable(a, b, q):
    # a عدد بدون دروغ، b عدد با یک دروغِ مصرف‌شده، q سؤال باقی
    if a + b <= 1:
        return True
    if q == 0 or a * (q + 1) + b > 2 ** q:
        return False
    return any(solvable(a1, b1 + a - a1, q - 1) and solvable(a - a1, b - b1 + a1, q - 1)
               for a1 in range(a + 1) for b1 in range(b + 1))

print(next(q for q in range(1, 10) if solvable(9, 0, q)))
```

### ۵.۲ سه وزنه برای ۱ تا ۹

[تمرین]
برچسب: three-weights
نوع: محض، الگوریتم
متن: یک ترازوی دوکفه‌ای و سه وزنه با وزن‌های یک‌رقمی و متفاوت داریم. وزنه‌ها را می‌شود در هر دو کفه گذاشت. وزنه‌ها را طوری انتخاب کنید که بتوان هر وزن صحیح از ۱ تا ۹ را اندازه گرفت. چند انتخاب هست؟ *(حدود ۱۵ دقیقه)*
راهنمایی ۱: آیا دو وزنه کافی است؟ دو وزنه حداکثر چند وزن مثبت می‌سازند؟
راهنمایی ۲: ۱، ۳، ۹ معروف است. ۳، ۴، ۵ را امتحان کنید.
پاسخ تشریحی: دو وزنه $a<b$ حداکثر ۴ وزن مثبت می‌سازند ($a$، $b$، $b-a$ و $a+b$)، پس سه وزنه لازم است. انتخاب‌های ممکن ۱۹ تاست. مثلاً با ۳، ۴، ۵: ۱ = ۴ − ۳، ۲ = ۵ − ۳، ۶ = ۴ + ۵ − ۳، ۷ = ۳ + ۴، ۸ = ۳ + ۵ و ۹ = ۴ + ۵. برنامه‌ی زیر همه را فهرست می‌کند. برخلاف انتظار، ۱، ۳، ۹ تنها جواب نیست.
جواب عددی: 19
برچسب کادر: تعداد انتخاب‌ها

[کد: قابل‌اجرا]
```python
from itertools import combinations, product
good = []
for w in combinations(range(1, 10), 3):
    reachable = {sum(s * x for s, x in zip(signs, w)) for signs in product((-1, 0, 1), repeat=3)}
    if all(v in reachable for v in range(1, 10)):
        good.append(w)
print(len(good), good)
```

### ۵.۳ عبور از پل

[تمرین]
برچسب: bridge
نوع: محض، الگوریتم
متن: چهار نفر شب باید از پلی بگذرند. هر کدام به ترتیب ۱، ۲، ۵ و ۸ دقیقه برای عبور وقت لازم دارند. حداکثر دو نفر با هم می‌توانند روی پل باشند و چون فقط یک چراغ دارند، هر گروه باید چراغ را با خودش ببرد. وقتی دو نفر با هم می‌روند، با سرعت کُندتر حرکت می‌کنند. کمترین زمان چقدر است؟ *(حدود ۱۰ دقیقه)*
راهنمایی ۱: راه‌حل طبیعی این است که سریع‌ترین نفر همه را همراهی کند. چقدر طول می‌کشد؟
راهنمایی ۲: اگر دو نفرِ کُند با هم بروند چه؟
پاسخ تشریحی: ۱۵ دقیقه. ۱ و ۲ می‌روند (۲)، ۱ برمی‌گردد (۱)، ۵ و ۸ با هم می‌روند (۸)، ۲ برمی‌گردد (۲)، و ۱ و ۲ می‌روند (۲). راه‌حل طبیعی، یعنی همراهی ۱ با همه، ۱۷ دقیقه طول می‌کشد. ایده: دو نفرِ کُند باید با هم بروند تا زمان کُندتر فقط یک بار حساب شود.
جواب عددی: 15
برچسب کادر: کمترین زمان (دقیقه)

[کد: قابل‌اجرا]
```python
import heapq
from itertools import combinations
people = (1, 2, 5, 8)
start = (frozenset(people), 0)   # کسانی که این سمت‌اند، جای چراغ
dist, pq = {start: 0}, [(0, 0, start)]
while pq:
    d, _, (here, lamp) = heapq.heappop(pq)
    if not here:
        print(d); break
    side = here if lamp == 0 else frozenset(people) - here
    for k in (1, 2):
        for g in combinations(side, k):
            new_here = here - set(g) if lamp == 0 else here | set(g)
            state = (frozenset(new_here), 1 - lamp)
            if d + max(g) < dist.get(state, 99):
                dist[state] = d + max(g)
                heapq.heappush(pq, (d + max(g), id(state), state))
```
